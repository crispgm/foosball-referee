## Introduction

A web application for foosball referee.

### Features

- Quick access via a single page web application.
- Designed for Portrait Mode of mobile phone.

## Dev

```shell
# Install dependencies
npm install

# Lint
npm run lint

# Start development server
npm run serve

# Build for production
npm run build

# Preview production build
npm run preview
```

Pushes to `main` build into the ignored `dist/` directory and publish the result to the `gh-pages` branch. GitHub Pages deployment runs in the same workflow; generated files are not committed to `main`.
